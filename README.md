One joke about Monday mornings, 46 characters: "I tried ghosting Monday. It has my work email." A setup and a punchline — Monday is inescapable because work owns your inbox — with no tired Monday cliche: no alarm, no coffee, no snooze button. The program writes exactly that text to `/output/entry.txt` (the grader's gate: UTF-8 text of 1 to 200 characters) and prints it to stdout. No network, no randomness, no clock, no environment input — two runs produce byte-identical output. See NOTES.md for the two other variants considered and why this one was chosen.

## Run it

```sh
node main.ts
```
